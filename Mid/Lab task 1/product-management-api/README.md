NestJS + TypeORM + PostgreSQL CRUD API for a small shop: manages **products** and **employees**.

## Tech used

- NestJS 11, TypeScript
- TypeORM with PostgreSQL (real database records, no in-memory arrays)
- Structure per feature: Module, Controller, Service, Entity, DTO, Migration
- class-validator for request validation, argon2 for password hashing
- Swagger UI at `/api` for quick testing

## Setup

### 1. Database (PostgreSQL 13 or newer)

1. Install PostgreSQL and open pgAdmin 4 (or `psql`).
2. Create a database named `shop_db`:
   ```sql
   CREATE DATABASE shop_db;
   ```
   No extension is needed: ids are generated with PostgreSQL's built-in `gen_random_uuid()`.

### 2. Environment

Copy `.env.example` to `.env` and put your own PostgreSQL password in `DB_PASSWORD`.

```bash
copy .env.example .env      # Windows
# cp .env.example .env      # Mac / Linux
```

`.env` is git-ignored, so the real password never goes to GitHub.

### 3. Install and run

```bash
pnpm install                # install packages (npm install -g pnpm if pnpm is missing)
pnpm run migration:run      # create the products and employees tables
pnpm run start:dev          # start on http://localhost:5001
```

Swagger UI: http://localhost:5001/api

## Products

| Field    | Type    | Rules                                  |
|----------|---------|----------------------------------------|
| id       | UUID    | Primary key generated by the database  |
| name     | string  | Required, max 100 chars                |
| category | string  | Required, max 50 chars                 |
| price    | number  | Required, ≥ 0, at most 2 decimals      |
| quantity | integer | Required, ≥ 0                          |

| Method | Endpoint       | Description                    | Success |
|--------|----------------|--------------------------------|---------|
| POST   | /products      | Create and save a product      | 201     |
| GET    | /products      | Return all saved products      | 200     |
| GET    | /products/:id  | Return the product with the ID | 200     |
| PATCH  | /products/:id  | Update the product with the ID | 200     |
| DELETE | /products/:id  | Delete the product with the ID | 200     |

Example `POST /products` body:

```json
{
  "name": "Notebook",
  "category": "Stationery",
  "price": 45.5,
  "quantity": 120
}
```

## Employees

| Field          | Type    | Rules                                          |
|----------------|---------|------------------------------------------------|
| id             | UUID    | Primary key generated by the database          |
| name           | string  | Required, max 100 chars                        |
| email          | string  | Required, valid email, unique (case-insensitive) |
| phone          | string  | Required, 7–15 digits, optional leading `+`    |
| password       | string  | Required, min 6 chars, stored hashed, never returned |
| age            | integer | Required, 18–100                               |
| yearsOfWorking | integer | Required, ≥ 0 and not more than `age - 14`     |

| Method | Endpoint        | Description                      | Success |
|--------|-----------------|----------------------------------|---------|
| POST   | /employees      | Create and save an employee      | 201     |
| GET    | /employees      | Return all saved employees       | 200     |
| GET    | /employees/:id  | Return the employee with the ID  | 200     |
| PATCH  | /employees/:id  | Update the employee with the ID  | 200     |
| DELETE | /employees/:id  | Delete the employee with the ID  | 200     |

Example `POST /employees` body:

```json
{
  "name": "Rahim Uddin",
  "email": "rahim@shop.com",
  "phone": "+8801711223344",
  "password": "dummy123",
  "age": 28,
  "yearsOfWorking": 4
}
```

## Errors

| Status | When                                                         |
|--------|--------------------------------------------------------------|
| 400    | Invalid body, unknown field in body, or ID is not a valid UUID |
| 404    | No product / employee with that ID                           |
| 409    | Employee email already exists                                |
